#  Brand IO – Power BI Dashboard

##  Project Overview

Brand IO is an interactive Power BI dashboard designed to analyze and visualize mobile brand data.

The dashboard provides an easy-to-understand view of brand performance, product information, and key business insights using interactive visualizations.

##  Objectives

- Analyze mobile brand performance
- Compare different brands
- Visualize important business metrics
- Identify trends and patterns
- Create an interactive and user-friendly dashboard

##  Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Excel / CSV Dataset

##  Dashboard Features

- KPI Cards
- Brand-wise analysis
- Interactive charts
- Brand comparison
- Slicers and filters
- Data visualization
- Interactive dashboard

##  Key Analysis

The dashboard allows users to:

- Compare different mobile brands
- Analyze brand performance
- Identify important trends
- Filter information interactively
- Understand business performance through visualizations
